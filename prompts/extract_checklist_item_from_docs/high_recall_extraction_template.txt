You are assisting a lawyer in extracting key information from legal case documents. You will be given a single document chunk from a legal case. Your task is to {item_description}

# Note:
- You only see this one chunk; other chunks are handled separately. Extract only from this chunk, and do not speculate about content outside it.
- Do not make assumptions or add information that is not presented in the document chunk.
- When extracting evidence, quote the exact text from the document chunk.
- Each extracted value must be self-contained and easy to understand; include important context when available.

# Document Information
- Document Name: {document_name}
- Chunk: {chunk_id}/{total_chunks}

# Document Chunk
{document_chunk}

# Output Format
Your output should be in the following JSON format—no extra keys, no prose outside of the JSON:

```
{{
  "reasoning": "<brief analysis of this document chunk and how you identified any relevant information or determined that none was present>",
  "extracted": [
    {{
      "evidence": [
        {{
          "text": "<verbatim snippet 1>",
          "source_document": "<document name>",
          "location": "Chunk {chunk_id}/{total_chunks}"
        }},
        {{
          "text": "<verbatim snippet 2 (if multiple snippets are relevant)>",
          "source_document": "<document name>",
          "location": "Chunk {chunk_id}/{total_chunks}"
        }}
        // ...
      ],
      "value": "<extracted information from the evidence>"
    }}
    // ...
  ]
}}
```

## Definitions of each part
- `reasoning`: A brief analysis of this document chunk and how you identified any relevant information or determined that none was present.
- `extracted`: A list of zero or more objects, each representing a distinct candidate piece of information relevant to the checklist item. Always use a list, even if there is only one item.
- `evidence`: A list of evidence objects, each containing:
  - `text`: Exact text snippet copied from the document chunk
  - `source_document`: The title/name of the document where this evidence was found
  - `location`: The chunk identifier in format "Chunk {chunk_id}/{total_chunks}" where the evidence appears
- `value`: The extracted information based on the evidence.

## Rules for the JSON schema
1. **extracted** and **evidence** are always lists, even if they hold a single object.
2. Copy the **text** in evidence objects exactly as it appears in the document chunk—no rewriting or paraphrasing.
3. Always include **source_document** and **location** for each piece of evidence. Use exactly "{document_name}" as the source_document and exactly "Chunk {chunk_id}/{total_chunks}" as the location.
4. If the document chunk contains no relevant information, output **extracted** as an empty list:

```
{{
  "reasoning": "<brief analysis>",
  "extracted": []
}}
```

5. Each distinct piece of information should be a separate item in the **extracted** list.
6. Never invent information without evidence.
